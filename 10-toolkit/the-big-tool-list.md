# The Big Tool List

Tools rot fast in this field — APIs die, sites block scrapers, projects get
abandoned. This list favors durable classics and notes maintenance status. Check
GitHub last-commit dates before trusting any tool's "current" status.

## Frameworks & platforms

| Tool | What it does | Status |
|---|---|---|
| **Maltego** | Link-analysis graphs + data transforms; the classic | Maintained (free CE tier) |
| **SpiderFoot** | Automated recon across 200+ sources | Open source, active |
| **Recon-ng** | Modular web recon framework | Active |
| **theHarvester** | Emails/subdomains/hosts from public sources | Active |

## People & identities

- **WhatsMyName** — username enumeration (web + CLI via Sherlock/Maigret/Blackbird)
- **Holehe** — email registration checks across 120+ sites
- **Epieos** — Gmail/Microsoft account linkage from email addresses
- **PhoneInfoga** — phone number footprint scanning
- **PimEyes / FaceCheck.ID** — face search (paid tiers; ethics apply)

## Social media

- **Instaloader / gallery-dl** — archive Instagram/public media
- **yt-dlp** — YouTube/media downloading incl. metadata+subtitles
- **pullpush.io** — Reddit historical search API (Pushshift successor)
- Twint/snscrape — X/Twitter: broken post-API changes; don't waste time

## Infrastructure

- **Shodan / Censys** — internet-connected device search
- **SecurityTrails / ViewDNS / DNSDumpster** — DNS history and mapping
- **crt.sh** — certificate transparency subdomain discovery
- **Amass** — deep attack-surface enumeration (authorized engagements)
- **PublicWWW** — source-code search (find shared analytics IDs, code reuse)
- **Wappalyzer / BuiltWith** — website technology fingerprinting

## Imagery & geolocation

- **Google Earth Pro** — free desktop, historical imagery
- **SunCalc** — shadow-based time/hemisphere analysis
- **InVID-WeVerify extension** — video keyframe verification suite
- **ExifTool** — the metadata standard
- **FotoForensics** — ELA analysis (interpret carefully)

## Archives & capture

- **Wayback Machine + archive.today** — covered in their own file
- **Hunchly** — paid but beloved: auto-captures every page during browsing with
  hashes, built for evidentiary rigor. If investigations go legal, worth every cent.
- **SingleFile extension** — one-click full-page saves

## Aggregators & paid intel

- **OSINT Industries** — email/phone enrichment used by pros (paid)
- **IntelligenceX** — search engine covering leaks/dark web/onions (paid tiers;
  evaluate legality of outputs for your jurisdiction)
- **OCCRP Aleph** — free; leaks + registries for financial investigations

## The meta-rule

Tools fail constantly. Manual methods (dorks, x-ray searches, archives) survive API
apocalypses. Learn the craft first; treat tools as accelerators, not crutches. When
a tool dies mid-investigation — and it will — the fundamentals carry you through.
